## 0. 目标与非目标

**目标**:zoom 常驻区(wide 系 1.7–2.7,健身场景实测高频区间)画质升档——越过切换带后用主摄光学取景替代超广角深裁剪(当前 2.68x 仅使用约 1/7 传感器面积)。

**非目标**:
- 每帧最优镜头(死区 / 冷却期内接受画质次优——用画质的次优换取零频闪切换,视频产品的正确取舍);
- 前置摄像头(无双广角虚拟设备,整套策略旁路,策略入口需带能力开关)。

## 1. 坐标系与不变量

- 全文使用 **wide 系**:超广角全传感器 = 1.0,画面中心为原点,横/纵半宽 = ±0.5。
- 1x 主摄 ≈ wide 2.0(标称 13mm→26mm),实机以 `virtualDeviceSwitchOverVideoZoomFactors` 读数为准;下文所有绝对参数进代码前改写为该读数的相对量(见 §3 ※ 标注)。
- **【不变量 I】** zoom 语义全程锚定 wide 系。镜头只是"用哪块传感器实现该取景"的实现载体:切换不改变 zoom 目标值、不改变 crop 框、不向构图/spring 系统发任何指令。切换前后显示构图在数值上严格连续(验收断言)。
- **【不变量 II】** 感知流(检测/身份/门)的输入假设 → 见 OPEN-1,解冻查勘必答后回填。

## 2. 设备与降级

- 采集设备换为 `.builtInDualWideCamera`(超广角+主摄虚拟设备),物理切换由系统托管(自动处理视差对齐、曝光/白平衡连续性),本策略层在其外包裹切换时机控制。
- **降级路径**(三种情形一律收敛到同一形态):无双广角机型(SE 系)/ MultiCam 不可用 / 系统拒绝切换(如低光)→ **纯超广角数字裁剪 = 现状**。最坏情况 = 功能不启用,风险有下界。

## 3. 参数表

设计推演值;**※ 标注者必须实机校准后方可进代码**。

| 参数 | 值 | 含义 |
|---|---|---|
| 死区(zoom) | 1.9 – 2.2 ※ | 通道一的迟滞带,带内维持当前镜头,差值用当前镜头数字裁剪补足 |
| 驻留 | 1.5 s | 通道一 / 前置门共用;**连续制**——条件中断即清零,非累计 |
| 出门线 | ±0.20 ※ | 锁定中心越过 → 通道二 force(距主摄物理边界留 0.05 反应余量) |
| 回门线 | ±0.15 ※ | 锁定中心回到线内 → 前置门开,开始计驻留 |
| 空间死区 | 0.15 – 0.20 | 双线之间:已在门内不算出、已在门外不算进 |
| 速度否决 | vel < 0.08 /s ※ | 前置门计时期间持续要求(vel 复用刀 1 预测的速度估计) |
| 冷却 | 5 s ※ | force 触发后启动;**仅锁"切向窄"方向**,永不锁"切向广" |
| 主摄物理边界 | ±0.25(= 切换点半宽) | 出门线 = 其 80%,回门线 = 60%(相对量定义) |

**触发量定义(钉死)**:通道二与前置门的判定量是**锁定框中心的 wide 系坐标**——不是 crop 框位置、不是 zoom 值。高 zoom 下用 crop 框判断会提前误触发。

## 4. 镜头仲裁表(高压低,上层永远压过下层)

```
1. SEARCHING/LOST 且丢失位置在安全区外(阈值见 OPEN-2)
   → 强制超广角,即刻(找人必须全视野)
2. 通道二 force(锁定中心越出门线)
   → 切超广角,即刻,无视冷却;动作本身写入冷却
3. 冷却期 → 钉死当前镜头(仅约束第 4 层)
4. 通道一 request(zoom 需求穿死区上界 + 前置门成立 + 冷却已过)
   → 常规切换(切向主摄)
5. 默认 → 维持现状
```

**前置门(进入判定)** = 三条件**同时、连续**满足 1.5s,任一中断计时清零:

1. 锁定中心在回门线(±0.15)以内;
2. 中心速度 < 0.08/s(正在明显移动的人 = 不知道他要停哪 = 不切);
3. zoom 需求 > 死区上界 2.2(画质需求真实存在)。

**三层防抖分工**(缺一有对应漏洞):

| 层 | 机制 | 治什么 |
|---|---|---|
| 一 | 空间迟滞(0.20 出 / 0.15 回双线) | 贴线蹭的空间噪声——蹭线者够不到回门线 |
| 二 | 驻留 1.5s(连续制)+ 速度否决 | 瞬态路过、走路摆动的锯齿逼近 |
| 三 | 冷却 5s(单边) | **真实大幅往返**——单次决策全对但序列行为错的场景;切换频率被数学封顶 |

第三层的单边锁定即可封顶整个循环:两个切换方向互为前提(想再"窄→广"必先经历"广→窄"),按住一个方向,循环频率即被按住。

## 5. 生命周期行为

- **初始 / 重置态**(开 App、LOST 回全景、手动解锁):超广角、zoom = 1.0。所有"回到起点"的路径收敛到同一状态,禁止残留态(半吊子状态是本工程已知 bug 模式)。
- **冷启动首切**:走通道一,不免驻留——开场 1.5s 画质次优无人察觉,规则统一 > 省 1.5s。
- **录制中**:自由切换,与非录制完全同规则(系统相机录制中切镜头是用户日常行为;视差跳变量级为亚像素~几像素,叠加在动态跟拍画面中不可读)。见 §7 验收 ①②。
- **停止录制**:不重置镜头(锁定还在,镜头状态跨录制会话延续);仅解锁 / LOST 触发重置。
- **SEARCHING 与冻结的仲裁**(消解表面冲突):
  - 目标被遮挡、丢失位置仍在当前视野内 → **冻结优先**,镜头不动(三态机原语义);
  - 目标因走出视野而丢、丢失前最后位置在安全区外 → **切广角优先**(冻结在看不见目标的窗口内无意义)。判据用丢失前最后锁定位置,现成数据。
- **找回后回程**(SEARCHING→LOCKED,zoom 从全景重新收敛):穿死区走通道一正常驻留,无特权——与冷启动同规则。

## 6. 切换瞬间豁免(切换帧 ±3 帧)

视差跳变(两镜头基线几毫米,近距主体亚像素~几像素位移)会被跟踪链误判为异常。豁免覆盖**三处,漏一即产生一次假 teleport**:

1. 邻域门:半径临时放宽;
2. DRIFT 诊断:静默;
3. pred 历史:按切换位移补偿,或重播种(实施时二选一,取更简单者并在回执说明)。

录制路径复用 tracking 渲染好的 buffer(录制掉帧修复时确立的架构),豁免自动继承——验收需确认该继承成立,而非假设。

## 7. 验收要点

1. **跨切换录制**:AVAssetWriter 时间戳 / 格式连续;录一段跨切换视频,相册逐帧检查切换点无坏帧、无方向错误;

## 9. 配套基建(与本卡同批解冻)

**StateDebouncer** —— 统一状态防抖原语:

```swift
final class StateDebouncer<State: Equatable> {
    // dwellSec: 迁移前条件需连续满足的时长(驻留,连续制)
    // cooldownSec: 迁移后禁止再次迁移的时长(冷却)
    func request(_ target: State, at now: TimeInterval) -> State  // 常规通道
    func force(_ target: State, at now: TimeInterval)             // 紧急通道:跳过驻留,但写入冷却
}
```

- 语义:`force` 可插队但消耗冷却额度("紧急只对第一次成立"的机制化);冷却期内 request/force 一律不生效(force 的方向豁免由业务层仲裁表表达,组件不感知方向);每次迁移打统一日志 `⏲ DEBOUNCE {name} {from}→{to} via={dwell|force} cd={剩余}`。
- **边界钉死**:组件只管时序(多久能变、变完锁多久),不管阈值(什么条件算要变)——双阈值/死区是领域知识,留在各业务层。防止演化成上帝类,违反单一权威铁律。
- 收编序:镜头切换(出生即用)→ SEARCHING 装牙(冷却 2s 防旋转门)→ lock 最短保持 / 手势冷却(纯重构,行为等价,低优先)。

## 附录F:平滑度判决——不引入新滤波层(【平滑度收口卡】2026-07-27)

**判决:d 读回台阶不用滤波/滑动平均处理。** 理由(防止后续反复):

1. **显示倍率 = 真实光学 × 数字裁剪,软件平滑不了"真实光学"那一项。**
   若对 d 读回滤波后再算 Z_digital:实际显示 = 真实d × (Zt/滤波d)。真实 d 是台阶、
   滤波 d 是平的,差值直接变成画面抖动——台阶只是从 Z_digital 搬进乘积,一点没少,
   还多 2-3 帧滞后(读回本已滞后 1 帧)变成持续尺度偏差。
   **这里要的是"更精确跟住台阶的 Z_digital",不是"更平滑的 Z_digital"。滤波给的正相反。**
2. **台阶是规律的**(下坡 −0.03,−0.03,−0.03,−0.06 四拍循环),不是噪声。规律用预测,噪声才用滤波。
3. 链上已有三级平滑(settle 低通+速率帽+velTau → cropZoomSpring 二阶弹簧),再叠一层
   钝化全局变焦响应,在别处付账;且本仓已有先例:缓推为盖闪动而加,生出整个重映射暴露面。
   **加机制盖症状 = 下一轮冒新症状。**

**唯一例外**:若查证表明读回是噪声而非规律台阶(跨轮四拍不稳定且无相位结构),
滤波是标准解,回 gate 重议。先验证,再决定。
